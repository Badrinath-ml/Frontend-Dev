# FoodEX

Simple HTML, CSS and JavaScript food-delivery project for the Web Technologies weekly assignments.

## Project map

- `home.html` — landing page, search and restaurant catalogue
- `restaurant-menu.html` — selected restaurant menu
- `cart.html` — localStorage cart
- `foodex-data.html` — Week 6/9 JSON + XML demonstration
- `foodex-notes.html` — Week 8 Fetch text demonstration
- `foodex-feedback.html` — Week 10 Fetch POST demonstration
- `login.html` — Week 1 login
- `register.html` + `register.js` — Weeks 2–4 registration and validation
- `style.css` — shared FoodEX theme
- `script.js` — navigation, search, menus and cart
- `foodex-menu.json` — restaurant-chain catalogue
- `foodex-menu.xml` + `foodex-menu.dtd` — complete XML menu
- `*-menu.txt` — individual restaurant menus

## Weekly mapping

1. Home + Login
2. Registration form
3. External CSS
4. JavaScript validation
5. Catalogue, restaurant menus and cart
6. XML + DTD
7. Review / skill test
8. Fetch text
9. Fetch JSON + XML
10. Fetch POST

The project intentionally stays framework-free so the implementation remains appropriate for a student weekly assignment.
