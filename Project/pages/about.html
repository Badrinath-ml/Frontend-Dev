FoodEX Project

A student web technologies project that grows from basic HTML forms and styling into JavaScript, Fetch API, data formats and a separate Angular implementation.

Project overview

FoodEX is a frontend-only food delivery demonstration. The main application uses HTML, CSS and JavaScript for restaurant discovery, menus, cart operations, static registration/login, JSON/XML data loading and a frontend admin food manager. Weeks 11–14 are kept separately in the FoodEX Angular folder as the Angular demonstration.
