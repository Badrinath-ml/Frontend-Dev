# Frontend-Dev

## FoodEx

FoodEx is a static food-ordering frontend. Open `Project/home.html` through a
local web server so the Fetch API can load the menu and demo data files.

The project menu is stored in `Project/foodex-catalog.xml` and validated by
`Project/foodex-catalog.dtd`. The data demonstration page compares the same
FoodEx menu format in JSON and XML, while the notes and feedback pages show
text loading and POST requests.


## Deployment structure

- `Project/` — main FoodEX Weeks 1-10 application, including the static login/register pages and frontend-only Admin food management.
- `Codex Angular/` — standalone Angular Weeks 11-14 demonstration.

Deploy `Project/` for the main FoodEX site. Deploy `Codex Angular/` separately only when you want to demonstrate Weeks 11-14.
